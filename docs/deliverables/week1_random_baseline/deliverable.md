# Week 1 — Random baseline (the floor)

**Assignment:** Build the random baseline for both reassembly games so later
adversaries have a chance-level floor to beat.
- **Game O (ordering):** put a record's shuffled fragments back in order — scored by Kendall's τ.
- **Game L (linkage):** guess which fragments belong to the same record — scored by pairwise F1.

**Result (the floor):** ordering τ ≈ 0 (no correlation); linkage F1 ≈ 0.017
(~5 correct pairs out of 300, pure chance). Everything in later weeks is measured
against this.

## Files

| File | Author | Function |
|---|---|---|
| `baseline-run2.py` | Michael | The random baseline runner. Random-shuffle ordering + random grouping guessers, Kendall τ / pairwise-F1 scoring, 23,000 Monte-Carlo runs, plots the null distribution. Entry point. |
| `baseline-loader.py` | Michael | JSONL loading helpers — loads `fragments.jsonl`, parses `answer_key.jsonl` into per-record true order, groups fragments by record. |
| `fragments.jsonl` | (data) | 200 fragments across 50 records, shuffled. Each = `{fragment_id, record_id, text}`. The identifier dataset (name / SSN / account / address per record). |
| `answer_key.jsonl` | (data) | Ground truth: `{fragment_id, record_id, position, field_type}` — the true order + grouping, withheld from the guessers. |

## Run

```
python baseline-run2.py
```
Deps: numpy, scipy, matplotlib. Reads `fragments.jsonl` / `answer_key.jsonl` from the current folder.
